A · 20Hardeware, Geheue & Terme▸Gemeester

Netwerk-hardeware

TermDefinisie
RouterBeheer dataverkeer tussen verskillende netwerke; kies die beste pad vir datapakkies.
SwitchKoppel toestelle binne dieselfde netwerk; stuur data direk na die regte toestel.
ModemSkakel digitaal ↔ analoog sodat data oor telefoon-/kabellyne reis.
NICKaart wat 'n rekenaar aan 'n netwerk koppel; stuur/ontvang data.
Access PointLaat draadlose toestelle aan 'n bekabelde netwerk koppel.

Geheue

  • RAM — vlugtig; stoor data tydelik, verdwyn as krag afgaan.
  • VRAM — geheue op die grafikakaart, spesifiek vir beelddata/GPU.
  • Cache — klein, baie vinnige geheue tussen SVE en RAM vir gereeld-gebruikte data.
  • Virtuele geheue — skyfarea wat as "ekstra RAM" dien wanneer RAM vol is.
  • Bit vs Byte — bis = kleinste eenheid (0/1); greep = 8 bisse, stel 'n karakter voor.
Spoedhiërargie: SVE-register → Cache → RAM → Skyf. Diagram toevoeging: Berging → RAM → Cache → SVE

Foute & verskynsels

  • Integer Overflow — waarde te groot vir die toegewese bisse.
  • Thrashing — te veel tyd spandeer om data tussen RAM en skyf te ruil → werkverrigting daal.
  • Plug & Play — outomatiese herkenning + drywer-installasie van nuwe hardeware.

Sekuriteit

  • Rootkit — stel kwaadwillige nutsmiddels wat versteekte afstandbeheer gee.
  • Zombie — toestel deur malware besmet, op afstand deur 'n hacker beheer (botnet).
  • Spoofing — voorgee om 'n ander (vertroude) bron te wees.
  • Phishing — bedrog-e-posse met skakels na kwaadwillige webwerwe.
  • Spam — ongewenste gemorspos.

Ander terme

  • Ergonomie — studie van mens & toestel interaksie vir gemak/veiligheid.
  • Groen rekenarisering — omgewingsvriendelike rekenaarpraktyke.
  • Data-ontginning — deursoek groot datastelle vir patrone.
  • Data-pakhuis — gesentraliseerde bewaarplek van data vir analise.
  • 2D-skikking — rye & kolomme; GUI: TStringGrid.
  • Semantiese soek — soek op betekenis/doel, nie net woorde nie.
  • Order By — sorteer; Group By — groepeer vir totale.
  • Append — voeg by die einde van 'n tekslêer.

OOP-basisterme

  • Enkapsulering — beperk direkte toegang tot attribute; toegang via metodes.
  • Klas — die "bloudruk"; Objek — 'n instansie van 'n klas.
  • Instansïëring — proses om 'n nuwe objek te skep.

Klein terme

  • Patch — klein, spesifieke regstelling; Service Pack — versameling regstellings.
  • VGA — analoog, slegs video; HDMI — digitaal, video + oudio, hoër resolusie.
  • API — stel reëls wat programme laat kommunikeer sonder om interne werking te verstaan.
  • Firewall — filter netwerkverkeer; voorkom NIE virusse nie (antivirus doen dit). ⚠️

Wolkberging

  • Voordele: toeganklik enige plek, outomatiese rugsteun, maklike deel, bespaar plek.
  • Nadele: benodig internet, sekuriteitsrisiko, lopende koste.

Verwerker

  • Funksie — voer berekeninge/instruksies uit ("brein").
  • Multi-tasking — verskeie programme gelyktydig.
  • Multi-threading — ÉEN program verdeel in drade/threads wat op kerne loop.

SSD / Kompressie / Rugsteun

  • SSD voordele: vinniger, geen bewegende dele (duursaam), stil, minder krag.
  • Verliesloos — geen data verlore (teks/dokumente); Verliesgewend — data verwyder (foto's/oudio/video, bv. JPEG/MP3).
  • Rugsteun — afskrif apart gestoor vir herstel.

Kraggebruiker & sagteware

  • Kraggebruiker — gevorderde gebruiker, intensiewe take; gradeer eerste GPU/SVE op.
  • Toepassingsagteware — spesifieke taak (Word, spel); Stelselsagteware — bestuur al aktiwiteite/hardeware (OS).
  • GUI doel — maak dit maklik/intuïtief via ikone i.p.v. teksopdragte.
  • Disk Cleanup — verwyder onnodige/tydelike lêers.
  • Drywer — laat OS met spesifieke hardeware kommunikeer.

VM / SaaS / VR-AR / POST

  • VM-uitdagings: benodig baie hulpbronne (RAM/krag), kan werkverrigting verlaag, kompleks, lisensies.
  • SaaS: wolk-gehuisves; gebruiker hoef nie te installeer/onderhou nie.
  • VR — volledig gesimuleerde omgewing (headset); AR — voeg digitale inligting bo-op die werklike wêreld (foon) — nuttig waar jy met die fisiese omgewing moet omgaan.
  • POST — kort diagnostiese toets by aanskakeling; Booting — volledige opstartproses tot OS gelaai.
C · 30Kommunikasie & Netwerke▸Gemeester

Protokol & e-pos

  • Protokol — stel reëls vir netwerkkommunikasie.
  • SMTP — stuur e-pos; POP3 — aflaai/verwyder na een toestel; IMAP — sinchroniseer oor verskeie toestelle (bly op bediener).
  • VPN — veilige, versleutelde koppeling van 'n afgeleë ligging.
  • Enkripsie — data na gekodeerde formaat sodat onbevoegdes dit nie kan lees nie.
  • Vlog — videoblog; Bandwydte — gemeet in bps/Mbps (bisse/sek).
  • Bandwydte-diefstal — iemand koppel onwettig aan jou Wi-Fi, of malware gebruik dit agtergrond.
  • Ekstranet — privaat netwerk met beperkte toegang aan eksterne partye.

Res van Afdeling C

  • VoIP — stem via internet; nadeel: benodig stabiele verbinding.
  • Netiket — reëls vir beskaafde aanlyn-gedrag (moenie HOOFLETTERS skryf nie).
  • WLAN voordele: mobiliteit, geen kabels; nadele: sekuriteitsrisiko, interferensie.
  • NIC funksie — laat rekenaar aan netwerk koppel.
  • Web 3.0 — gedesentraliseer, semanties, persoonlik. KI in semantiese soek — ontleed konteks/betekenis.
  • CSS voordeel — konsekwente styl van een plek, maklik onderhou.
  • Multi-laag (MFA) — 2+ metodes (wagwoord + kode + vingerafdruk); Biometries — vingerafdruk/gesig/iris.
  • Stroom — speel intyds, stoor nie volledige lêer; Aflaai — volledige lêer eers oorgedra.
  • BitTorrent — P2P; verdeel lêer in stukkies, laai gelyktydig van verskeie gebruikers.
  • SSL — enkripteer data tussen blaaier en bediener (https, bankwese).
D · 20Data- & Inligtingbestuur▸Gemeester

Getallestelsels

  • Binêr (basis 2) — 0/1; Denêr (10) — 0–9; Heksadesimaal (16) — 0–9 + A–F.
  • Getal "1D1" het 'n D → dis heksadesimaal (binêr/denêr gebruik geen letters).

Sleutels & integriteit

  • Primêre sleutel — uniek identifiseer elke rekord; nie leeg/dupliseer nie.
  • Vreemde sleutel — veld wat verwys na die primêre sleutel van 'n ander tabel (skep skakel).
  • Referensiële integriteit — vreemde sleutel moet ooreenstem met 'n bestaande primêre sleutel.
  • Relasionele databasis — data in verskeie verwante tabelle via sleutels.

Anomalieë ⭐

TipeBeskrywing
InvoegKan nie nuwe data byvoeg sonder onnodige data nie.
SkrapSkrap een rekord, verloor per ongeluk ander data.
OpdateringDieselfde data op meerdere plekke; raak onkonsekwent.
OortolligheidData onnodig herhaal (bv. naam 3×).

ERD

  • 1:1 — een hoort by een; 1:N — een het baie (een verkoper, baie advertensies); M:N — benodig tussentabel.
  • Teken: benoem tabelle, lys veldname, merk primêre/vreemde sleutels, trek lyne met kardinaliteit.

  • Verifikasie — handmatige dubbelkontrole (dubbele-invoer, proeflees) — verskil van outomatiese validering.
  • Ouditspoor — hou wie, wat, wanneer by; tipes: toevoeging/opdatering/skrapping. Nadeel van nasporing: baie stoorplek, privaatheidskwessies.
  • DBA — sekuriteit, rugsteun/herstel, werkverrigting, ontwerp, integriteit.
  • Enkripsie — data na gekodeerde vorm.

Reset vs Rewrite vs Append ⭐

StellingEffek
ResetOpen vir LEES.
RewriteSkryf; skep nuut of vee alles uit.
AppendVoeg by die einde by, vee niks uit.
  • Reset→Append: uitvoeringsfout (kan nie uit skryf-modus lees nie). Reset→Rewrite: geen afvoer (lêer is leeg, eof onmiddellik).

UML & metodes

  • + publiek, − privaat. Accessor — lees terug (Get); Mutator — verander (Set); Konstruktor (Create) — skep objek + initialiseer; toString — stringvoorstelling.
  • Funksie — gee 'n waarde terug (Length, Copy, Power); Prosedure — geen waarde (Writeln, ShowMessage, CloseFile).

Datastrukture & ewekansig

  • 1D — enkele lys; 2D — rooster, GUI: TStringGrid.
  • Ewekansig 45–75: iRandom := Random(75-45+1)+45;
  • Onewe: If (n mod 2) <> 0 Then
  • For — jy ken die aantal; While — aantal onbekend, hang van toestand af (lees lêer tot eof).

Nasporing — metode

  • Kolom per veranderlike + lus-toestand + afvoer. Werk reël-vir-reël; toets toestand elke keer.
Logiese fout-les: lus loop glad nie (0-afvoer)? Kyk eers na die vergelykingsoperator — var1 > var2 (2>6 onwaar) moet var1 < var2 wees → Totaal = 14.
F · 30Geïntegreerde Scenario▸Gemeester

Kernkonsepte

  • GIGO — swak invoer → swak uitvoer, ongeag verwerking. Voorkom: validering, opleiding, dubbelkontrole.
  • Digitale kloof — ongelykheid in toegang/vaardighede. Oorbrug: gratis internet/toestelle, digitale geletterdheidsopleiding.
  • Digitale burgerskap — verantwoordelike, etiese tegnologiegebruik.
  • Gig-ekonomie — korttermyn, buigsame kontrakwerk; nadele: geen werksekerheid/voordele.
  • Kantooroutomatisering — outomatiseer roetine-take. Robotte voordele: hoër produktiwiteit, 24/7, veilig vir gevaarlike take.
  • KI — stelsels wat menslike intelligensie-take verrig. Voordele: vinnig, 24/7. Nadele: hallusinasies, geen ware begrip, etiese kwessies, werkverliese.
  • Kripto — gedesentraliseer, laer koste; nadele: wisselvallig, geen regulering, hacking, hoë energie.
  • Digitale voetspoor — data-spoor van aanlyn-aktiwiteit; aktief/passief.
  • Blokkeerketting — gedesentraliseerde digitale grootboek, rekords kan nie agterna gewysig word nie; gebruik: finansies, voorsieningsketting.
  • Big Data "V's" — Volume, Snelheid (Velocity), Verskeidenheid (Variety), Waarheidsgetrouheid (Veracity).
  • IoT — slimhuis-toestelle, fiksheidsmonitors. Uitdaging: swak/verstek-sekuriteit, vatbaar vir hacking/botnet.
  • DoS — oorlaai stelsel met verkeer sodat wettige gebruikers toegang geweier word.
  • Data-sekuriteit — sterk wagwoorde/MFA, firewalls, antivirus, enkripsie, rugsteun, toegangsregte, opdaterings, opleiding.
  • Multi-platform OS — loop oor verskeie toesteltipes/platforms (Windows/macOS/Linux, foon/tablet).
GPU: verseker goeie gebruikerservaring (grafika). Virtualisering: hardeware na verskeie virtuele masjiene. 4IR: digitale transformasie.
