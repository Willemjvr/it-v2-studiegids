The 10 golden answer rules (every paper)

  • 1. Check the marks first: (2) = 2 facts, (4) = 4 facts or 2 facts + 2 reasons. Don't give 1 long sentence for 3 marks.
  • 2. Define = 1 core fact in a full sentence; "state/give/list" = just the fact, NO explanation.
  • 3. Explain = fact + reason (why). Just the fact = ½ mark.
  • 4. Write acronyms in full: URL, SMTP, RAM, VPN, GPL … otherwise you lose the mark.
  • 5. "Give TWO" = exactly two, not one, not three.
  • 6. Scenario question (F): definition + apply it to the scenario. Refer to the scenario to get full marks.
  • 7. Compare/differentiate: give BOTH sides (A is … whereas B is …).
  • 8. Motivate/justify: give the reason (why), not just the statement.
  • 9. ERD/UML: underline or ★ the primary key, mark the FK, show cardinality (1 / ∞).
  • 10. Trace table: work line-by-line, one column per variable, test the condition every time.

Network hardware

TermWhat it is / does
RouterConnects different networks (home network → internet); chooses the best path for data.
SwitchConnects devices within the same network; sends data only to the correct device.
ModemConverts digital ↔ analogue so data can travel over phone/cable lines.
NIC (Network Interface Card)Connects the computer to a network. Nov 2024 Q2.4.1
Access Point (WAP — Wireless Access Point)Lets wireless devices join a wired network.

Memory & storage

  • RAM (Random Access Memory) — volatile: holds programs/data temporarily for the CPU. Nov 2024 Q2.1.1
  • ROM (Read Only Memory) — non-volatile: permanent instructions (firmware/BIOS).
  • VRAM (Video Random Access Memory) — memory on the graphics card (GPU), stores image data.
  • Cache — small, very fast memory near/on the CPU; holds frequently used data. Nov 2024 Q2.1.2
  • Web caching — visited websites' images/info are stored on your disk; next visit loads only the changed data → saves time and data.
  • Virtual memory — disk space used as "extra RAM" when RAM is full (slower — it goes through storage). Nov 2025 Q2.2.2
  • Register — smallest, fastest storage inside the CPU.
Speed order (fastest → slowest) — Nov 2025 asked this: CPU cache → VRAM → RAM → SSD → HDD. Why VRAM before RAM? It is directly on the graphics card, closer to the processor.

Units & characters

  • Bit — smallest unit (0 or 1). Byte — 8 bits; usually one character.
  • Hierarchy: bit → byte → KB → MB → GB → TB (about ×1024 each step).
  • ASCII (American Standard Code for Information Interchange) — code that represents characters as numbers.

Input & output — units of measurement

  • Scanner / mouse — sensitivity/quality in dpi (dots per inch).
  • Screen resolution — in pixels; screen size in inches (diagonal).
  • Printer resolution — dpi; printer speed — ppm (pages per minute).

Motherboard (Nov 2025: TWO functions)

  • Functions: (1) connects all the components, (2) distributes power, (3) provides slots/ports, (4) carries data via buses. Nov 2025 Q2.1.1
  • Bus vs point-to-point: a bus is one shared path for many devices → only one can talk at a time → slower. Point-to-point is a direct connection between two devices → faster. Nov 2025 Q2.1.2
  • Why a GPU improves performance: the GPU takes graphics tasks over from the CPU; many small cores do it in parallel. Nov 2025 Q2.1.3
  • Ports: USB (Universal Serial Bus), HDMI (High-Definition Multimedia Interface — video + audio, digital), VGA (Video Graphics Array — older, analogue, video only), Thunderbolt (one cable, very fast).
  • Slots (expansion cards): ZIF (Zero Insertion Force) socket = CPU; DIMM (Dual In-line Memory Module) slots = DDR RAM; PCI Express (Peripheral Component Interconnect Express) = graphics card (fast data transfer).

Errors & phenomena

  • Integer overflow — value too big for the number of bits → wrong value.
  • Thrashing — system spends too much time swapping data between RAM and disk → very slow.
  • PnP (Plug and Play) — automatic recognition + driver installation of new hardware.
  • Archiving — old documents are moved from primary to secondary storage (frees the main location); NOT the same as backup (backup = copy). Nov 2025 Q2.3

Software & the operating system

  • Application software — for one specific task. System software — manages everything (the OS).
  • OS functions: manage resources, manage files, manage devices (drivers), user interface, security, manage processes.
  • Multiprocessing — a CPU with MANY cores (multi-core) lets the OS do many tasks at once. Nov 2024 Q1.2.2 · Nov 2025 Q2.2.1
  • Disk Cleanup — removes unnecessary/temporary files.
  • Modular design of a computer (advantages): easy to repair, easy to upgrade, customise specs, cheaper to replace one part. Nov 2024 Q2.3.1
  • Alpha vs Beta version: Alpha = earlier, less polished, internal; Beta = closer to final, external for broader testing.
  • High-level vs low-level languages: high-level = close to human language, easier, portable; low-level = close to machine code, fast but hard to write. EC Sept 2025 Q2.7.4

BIOS & booting ⭐

  • BIOS (Basic Input/Output System) functions: (1) controls hardware at the lowest level, (2) POST (checks hardware is present and working), (3) finds and loads the OS, (4) offers configuration options (CMOS). Nov 2024 Q2.3.2
  • Why BIOS is on non-volatile memory: so it keeps data when power is off and settings reload next time. Nov 2024 Q2.3.3
  • CMOS (Complementary Metal-Oxide Semiconductor) — stores the BIOS settings. Firmware/BIOS is stored on ROM.
  • POST (Power-On Self-Test) — a short test at switch-on. Booting — the full startup process.

Updates

  • Patch — small, specific fix. Service Pack — a collection of patches. Nov 2024 Q1.3.4
  • Disadvantages of automatic updates: unexpected data usage, device slows/interrupts, inconvenient restart, unwanted update, data loss, compatibility issues. Nov 2024 Q6.7

Processor (CPU) & GPU

  • CPU (Central Processing Unit) function — performs calculations and instructions (the "brain").
  • Machine cycle (4 steps): Fetch → Decode → Execute → Store. EC Sept 2024 Q2.1.3
  • Multi-tasking — many programs run "at once". Multi-threading — ONE program splits work into threads across cores.
  • Cores — physical processors; more = more simultaneous work. Clock speed (GHz) — the CPU's speed.
  • Factors that determine a GPU's (Graphics Processing Unit) power: VRAM size, memory type/bandwidth, clock speed, number of cores, generation. Nov 2024 Q2.2
  • Virtual memory slows the computer: it is read from storage (disk), and swapping between RAM and disk is slow. Nov 2024 Q2.1.3
  • Paging — the process of swapping "pages" of memory between RAM and hard disk. Thrashing — when the computer keeps swapping and "freezes".

Security

  • Firewall — filters network traffic; does NOT prevent viruses. ⚠️
  • Antivirus — finds and removes malware.
  • Encryption — data in coded form, unreadable without a key.
  • MFA (Multi-Factor Authentication) — 2+ methods: something you know + have + are.
  • Biometrics: fingerprint, facial recognition, iris scan, voice. Nov 2025 Q2.5.1

Compression & backup

  • Lossless — no data lost (text/documents). Lossy — data permanently lost (JPEG, MP3, video).
  • Backup — copy of data elsewhere. Types: full, incremental.
  • Physical data integrity — protect against power failure, natural disasters, theft. Hardware: UPS (Uninterruptible Power Supply), RAID (Redundant Array of Independent Disks), access control, electronic locks, surge protectors. Nov 2024 Q4.2

Cloud & SaaS

  • Cloud computing — shared resources offered as services over the internet (store/process data). Nov 2024 Q2.5.1
  • Why cloud lowers hardware requirements: processing in the cloud → cheaper/lower local specs; storage in the cloud → less local storage; cloud backup → no dedicated backup server. Nov 2024 Q2.5.2
  • SaaS (Software as a Service) — software in the cloud; user does not install/update/maintain.
  • API (Application Programming Interface) — set of rules so programs can talk to other services.

VR vs AR

  • VR (Virtual Reality) — fully simulated world. AR (Augmented Reality) — digital info on top of the real world. Nov 2024 Q2.6.1
  • VR benefits (practical): interactive training, participate remotely, simulate the real course/environment, create opponents. Nov 2024 Q2.6.2
  • VR limitations: expensive equipment, motion sickness, needs a powerful computer, isolates you.

Virtualisation & distributed processing

  • Virtualisation — one physical computer runs several virtual machines. Nov 2024 Q1.2.4
  • Distributed processing: many computers work together on one big task — faster (parallel), share resources, one can fail without everything stopping. Nov 2024 Q6.3.4

Network basics

  • Protocol — a set of rules for communication.
  • LAN (Local Area Network) — small area. WAN (Wide Area Network) — large area. PAN (Personal Area Network) — personal range (smartwatch + phone via Bluetooth).
  • IP address (Internet Protocol address) — uniquely identifies a device on the network so it can communicate. Nov 2024 Q3.1.4
  • DNS (Domain Name System) — translates domain names to IP addresses.
  • ISP (Internet Service Provider) — provider of internet. Nov 2024 Q2.4.2
  • Bandwidth — how much data per second moves over the network; measured in bps / Mbps / Gbps. Nov 2024 Q3.1.2
  • Range vs bandwidth: range = how far the signal reaches; bandwidth = how much data per second.
  • Client-server (reasons): central security/access control, central backup, shared resources, sign in from anywhere, scalable.
  • NOS (Network Operating System) — OS that manages network resources.
  • HAN (Home Area Network) — home network; WLAN (Wireless Local Area Network) — wireless LAN. Node — any device on the network.
  • AUP (Acceptable Use Policy) — document that explains correct use of the network.
  • Broadband — high-speed, always-on connection. Backbone — the internet's main data path.
  • FTTH (Fiber To The Home) — fibre right to your home.
Intranet vs Extranet vs Internet: Intranet = private, employees only; Extranet = private + limited access for clients/suppliers; Internet = for everyone. Nov 2025 Q1.1.3
Internet vs World Wide Web (WWW): the Internet = the physical network of interconnected networks; the WWW = the collection of web pages/services that run on the internet. EC Sept 2024 Q3.1.1

Network topology (Nov 2024 asked STAR)

  • Star advantages: if one cable/switch-port fails, the other devices still work; easy to find faults (own cable per device); easy to add/remove devices. Nov 2024 Q3.1.5

Bandwidth, streaming & speed

  • Buffering — weak/far signal from the access point, interference, too few access points for many users, everyone shares the same bandwidth.
  • Throttling — provider makes your overall speed slower. Shaping — makes important traffic faster.
  • Streaming — plays in real time. On-demand — pre-recorded, any time. Nov 2024 Q3.5.1
  • VoIP (Voice over Internet Protocol) — voice calls over the internet; drawbacks: needs a stable connection, latency.
  • BitTorrent — P2P (peer-to-peer): file in pieces from many users.

E-communication terms

  • SMS (Short Message Service) — short text messages (±160 characters) via mobile network. IM (Instant Messaging) — real-time text (WhatsApp, Teams).
  • Blog — regular articles; Microblog — short posts (X); Vlog — video blog.
  • Podcast — audio programme (episodes); Vodcast — podcast in video.
  • Videoconference — real-time video + audio with many participants.
  • e-learning — learning via digital platforms, at a distance.

Websites & web services

  • Static website — same for everyone, updated by hand. Dynamic website — content from a database; benefits: personal content, always up to date, interactive. Nov 2024 Q3.3.1
  • Cookie — a small text file that tracks your activity/preferences; benefits: remember preferences, save time, personal recommendations. Nov 2024 Q3.3.2
  • Invisible data collection: cookies, tracking pixels, device fingerprinting.
  • SEO (Search Engine Optimization): keywords, meta-descriptions, quality content, backlinks.
  • Web 1.0 vs Web 3.0: Web 1.0 = static, you just read; Web 2.0 = social; Web 3.0 = semantic + decentralised.
  • Semantic search — understands meaning → more accurate.
  • Mediated search — results first chosen by people/editors.
  • QR code (Quick Response) benefits: contactless, more secure (unique per ticket), easier organisation, saves paper, links to more data. Nov 2024 Q3.4.2

Security & behaviour

  • DDoS (Distributed Denial of Service). Nov 2024 Q3.5.2 Prevent: more bandwidth, upgrade network, queueing system, traffic management, bot prevention. Nov 2024 Q3.5.2(b)
  • OTP (One-Time Password) — one-time PIN; effective because: valid only once, short time, sent to YOUR phone, hard to steal.
  • Security token — a small device that generates a new code every few seconds.
  • Social engineering — attacker deceives PEOPLE into giving information.
  • Recognise a phishing email: sender address, suspicious links, urgent language, spelling errors, request for personal info.
  • How to tell a website is secure: https, security symbol, green address bar, SSL/digital certificate. Nov 2024 Q6.1.1
  • SSL encryption: public key encrypts, private key decrypts. Nov 2024 Q6.1.2
D · 20–24Databases & Information management▸Mastered

Number systems

  • Binary (base 2) — 0/1. Denary (base 10) — 0–9. Hexadecimal (base 16) — 0–9 + A–F.
  • "1D1" has a letter → hexadecimal.

Keys & integrity ⭐

  • Primary key (PK) — uniquely identifies each record; not empty, not duplicated. Nov 2023 Q4.1.1
  • Foreign key (FK) — field that refers to the PK of another table.
  • Referential integrity — the FK must match an existing PK.
  • Alternate key — another field that is also unique (could have been the PK). Nov 2024 Q4.3.2
  • Relational database — data in several related tables.
  • Composite key — a PK made of two or more fields.
  • Entity integrity — the PK cannot be null. Referential integrity — the FK must refer to an existing PK.

Data properties & data types

  • Currency — data is up to date. Relevance — useful for the purpose.
  • Accuracy — data must be precise. Nov 2024 Q4.1.5
  • Consistency — data must have the same format everywhere. Nov 2024 Q4.1.5
  • Choosing a data type: a field you must sort or calculate (e.g. "Experience") → integer, not text. Nov 2025 Q4.1.1
  • CellNumber → text/string (a phone number is not a number to calculate with). Nov 2024 Q4.1.2(b)
  • Metadata — data about data; adds value by giving context, easing interpretation, supporting decisions. Nov 2024 Q4.4

Normalisation ⭐

  • Purpose — remove redundancy; split into logical tables. Nov 2023 Q4.3.1 · Nov 2024 Q4.3.1
  • Recognise: repeating fields (Item1, Item2, Item3) or a field that depends on a non-key field = unnormalised.
  • Solution: move the dependent fields to a separate table, link with an FK. Nov 2023 Q4.1.3(b)

ERD — draw a database diagram ⭐

  • 1:1 — one-to-one. 1:N — one has many. M:N — needs a linking table.
  • Step-by-step: (1) a box per table with the name on top, (2) list field names, (3) underline or ★ the PK, (4) mark each FK, (5) line between the FK side and the PK side with cardinality (1 / ∞).
┌───────────────┐         ┌──────────────────┐
│  TBSellers    │         │  TBAdverts       │
├───────────────┤         ├──────────────────┤
│ ★ SellerID    │1        │ AdvertID         │
│ SellerName    │─────────│ ★ AdvertID       │
│ ContactNumber │         │ FK SellerID      │
└───────────────┘         └──────────────────┘
  (1 at the PK side; ∞/many at the FK side)

SQL core statements

  • SELECT fields FROM table WHERE condition — retrieve data.
  • ORDER BY — sort (ASC/DESC). GROUP BY — group for totals (COUNT, SUM).
  • HAVING filters after GROUP BY; WHERE filters before grouping. Nov 2024 Q1.3.5

  • Why validation does not replace verification: valid data is only in the correct format, not necessarily factually correct. Nov 2023 Q4.2
  • DateTimePicker already does validation (format is right). Verification still needed: the user visually checks the date is correct.

Database management

  • Audit trail — records WHO, WHAT, WHEN changes were made. Nov 2023 Q4.4.1
  • Server database needed when many users from many places need simultaneous access. Nov 2023 Q4.3.2
  • DBA (Database Administrator) — security, backup, performance, design, integrity.
  • Security methods: access control (passwords/biometrics), encryption, backups, firewall. Nov 2023 Q4.4.2
  • Open-source DBMS: MySQL, PostgreSQL. Proprietary: SQL Server, Oracle, Access.

SQL query templates

-- Retrieve data (filter + sort):
SELECT  field1, field2
FROM    table
WHERE   condition
ORDER BY  field  ASC/DESC;

-- Totals / counts (group):
SELECT  field, COUNT(*) / SUM(field)
FROM    table
GROUP BY  field
HAVING    condition_after_grouping;

-- Join two tables (FK → PK):
SELECT  a.field, b.field
FROM    tableA a, tableB b
WHERE   a.fk = b.pk;
Rule: WHERE filters before grouping, HAVING filters after GROUP BY. ORDER BY sorts, GROUP BY groups for COUNT/SUM.

Trace-table method

  • 1. Make a column for each variable + the condition + the output.
  • 2. Work line-by-line through the code; fill a new row for each step.
  • 3. Test the condition every time (TRUE/FALSE) — it decides whether the loop runs.
  • 4. Write the output (Display) in the correct order.
  • 5. Stop when the condition becomes FALSE. Nov 2023 Q5.2

Algorithm-writing method (6–8 marks)

  • 1. Declare variables (arrays, counters).
  • 2. Read the file via while not eof; split lines (Copy/Pos).
  • 3. Store in arrays.
  • 4. Compare in a loop to find highest/lowest.
  • 5. Display the answer.

Calculations (rare, but know the formulas)

Data-transfer time: time = data size ÷ bandwidth. File in MB, speed in Mbps → convert (×8 for byte→bit).
Storage space: total = number of records × size per record. Image: resolution × colour depth (bits) × frames × seconds.
Bandwidth: how much data per second (bps/Mbps/Gbps). 1 byte = 8 bits.

⚠️Common mistakes that cost marks▸
  • Acronym not in full — "RAM" instead of "Random Access Memory" = no mark. Always write it in full.
  • Firewall "prevents viruses" — FALSE. A firewall filters network traffic; antivirus handles viruses.
  • RandomRange(A,B) — you think B is included. B is NOT included: RandomRange(10,13) = 10, 11, 12.
  • UpCase on a String — UpCase works only with Char; use UpperCase for a String.
  • MOD with Real — MOD/DIV work only with Integer.
  • CEIL of a negative — CEIL(−2.3) = −2 (not −3). "Up" = towards the larger number.
  • CASE with String/Real — CASE works only with ordinal types (Integer/Char/Boolean).
  • PK duplicate/null — a primary key cannot be null or duplicate.
  • Validation = verification — validation is automatic (format/range); verification is human (double-check).
  • ERD cardinality reversed — the "1" at the PK side, "many/∞" at the FK side.
  • PK not underlined / FK not marked in ERD and UML — loses marks.
  • Explain without a reason — "explain why" asks for a reason, not just the fact.
  • 1 long sentence for 3 marks — the marker counts separate facts; break it up.
  • Scenario ignored (F) — give the definition but don't apply it to the scenario = half the marks.
  • Trace table skips steps — work line-by-line; test the condition every loop.
  • "Compare" gives only one side — give BOTH (A is …; B is …).
  • Too few or too many points — "give TWO" but you give one (or three). Give exactly the number asked.
  • Bandwidth unit wrong — bandwidth is measured in bps/Mbps/Gbps, not in "metres" (that's range).
